# Fit-Blog
A project I made as part of CS50's course using HTML, CSS, JavaScript, and Bootstrap for styling. The project is the frontend of a blog website that contains multiple pages, each with a different layout.  


## Contents
This project contains 4 pages:


### Home
The landing page of the website, showing a glimpse of recently added reads.

![alt text]( "Home page")

### Blog
This is where it gets interesting! The slide show at the top highlights 
the hottest topics, while the rest of the articles are shown in the cards below.


### About
The about page contains a synopsis of the company and how it started.


### Contact
The contact page is where you can contact the company to send them an article or reach out. 
It contains a form where the user will enter their email address, email title, and the body of the email and send it.
Using bootstrap, the fields are all validated on the client side.
